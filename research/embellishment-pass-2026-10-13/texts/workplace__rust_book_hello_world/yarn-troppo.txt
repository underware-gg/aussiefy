### Project Directory Setup

Strewth, where do I start? With a directory, that’s where: somewhere to keep yer Rust code. Now, Rust doesn’t give a flyin’ toss
where yer code lives, could be under the house with the redbacks for all it cares, but for the exercises and projects in this book,
we reckon ya make a _projects_ directory in yer home directory and keep all
yer projects in there, nice and tidy, so ya know where the lot is.

So fire up a terminal and punch in these commands. They make a _projects_ directory,
then a directory for the “Hello, world!” project inside it. Easy as.

If yer on Linux, macOS, or PowerShell on Windows, it’s this lot:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

And if yer stuck with Windows CMD, ya poor bugger, it’s this:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Next up, ya make a new source file and call it _main.rs_. Rust files always end in
the _.rs_ extension, every bloody one of ’em. Got more than one word in yer filename? Then the
usual go is to whack an underscore between ’em so they don’t run together. So it’s
_hello_world.rs_, not _helloworld.rs_, which looks like a sneeze.

Now crack open that _main.rs_ file ya just made and punch in the code from Listing 1-1. Here it is, all three lines of it:

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save it, then nip back to yer terminal window in the
_~/projects/hello_world_ directory. On Linux or macOS, punch in these
commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, mind, it’s `.\main` instead of `./main`, cos Windows always has to be different:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Doesn’t matter what operating system yer on, the string `Hello, world!` should pop up in
the terminal. And if ya don’t get that output? No dramas. Have a squiz back at the
[“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation
section for where to get a hand.

But if `Hello, world!` did come up? Well, good on ya, mate! You’ve officially written a Rust
program. Fair dinkum. That makes ya a Rust programmer—welcome to the club! First round’s on you.
