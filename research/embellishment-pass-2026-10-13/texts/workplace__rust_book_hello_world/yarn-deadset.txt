### Project Directory Setup

First up, ya make a directory to keep yer Rust code in. Rust doesn’t give a toss
where yer code lives, but for the exercises and projects in this book,
we reckon ya should make a _projects_ directory in yer home directory and keep all
yer projects in there.

Open a terminal and punch in these commands to make a _projects_ directory
and a directory for the “Hello, world!” project inside the _projects_ directory.

For Linux, macOS, and PowerShell on Windows, punch in this:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

For Windows CMD, punch in this:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Next, make a new source file and call it _main.rs_. Rust files always end in
the _.rs_ extension. If yer usin’ more than one word in yer filename, the
usual go is an underscore to split ’em up. Say, use
_hello_world.rs_, not _helloworld.rs_.

Now open the _main.rs_ file ya just made and punch in the code in Listing 1-1.

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save the file and head back to yer terminal window in the
_~/projects/hello_world_ directory. On Linux or macOS, punch in these
commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, punch in the command `.\main` instead of `./main`:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Whatever operating system yer on, the string `Hello, world!` should print to
the terminal. If ya don’t see this output, have a squiz back at the
[“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation
section for ways to get a hand.

If `Hello, world!` did print, good on ya! You’ve officially written a Rust
program. That makes ya a Rust programmer—welcome!
