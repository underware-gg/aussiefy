### Project Directory Setup

Righto, first thing ya do is make a directory to keep yer Rust code in. Rust couldn’t care less
where yer code ends up, but for the exercises and projects in this book,
we reckon you’re best off makin’ a _projects_ directory in yer home directory and chuckin’ all
yer projects in there.

So fire up a terminal and punch in these commands, which make a _projects_ directory
and, inside that, a directory for the “Hello, world!” project.

On Linux, macOS, and PowerShell on Windows, it’s this:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

On Windows CMD, it’s this instead:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Next up, make a new source file and call it _main.rs_. Rust files always end in
the _.rs_ extension. Got more than one word in yer filename? Then the
usual go is to stick an underscore between ’em. So it’s
_hello_world.rs_, not _helloworld.rs_.

Now open up that _main.rs_ file ya just made and punch in the code from Listing 1-1.

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save it and head back to yer terminal window in the
_~/projects/hello_world_ directory. On Linux or macOS, punch in these
commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, it’s `.\main` instead of `./main`:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Whatever operating system yer on, the string `Hello, world!` should come up in
the terminal. If ya don’t get that output, have a squiz back at the
[“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation
section for where to get a hand.

If `Hello, world!` came up, good on ya! You’ve officially written a Rust
program, which makes ya a Rust programmer—welcome to the club!
