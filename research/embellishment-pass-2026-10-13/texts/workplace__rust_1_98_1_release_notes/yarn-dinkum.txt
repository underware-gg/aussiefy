Good news: the Rust team's just put out a new point release of Rust, 1.98.1. Rust's a programming language that's giving every man and his dog what they need to build reliable and efficient software.

If you've already got an older version of Rust on your machine through rustup, getting Rust 1.98.1 is as easy as:

```
rustup update stable
```

Haven't got it yet? No worries, you can [get `rustup`][rustup] from the right page on our website.

[rustup]: https://www.rust-lang.org/install.html

## What's in 1.98.1

Rust 1.98.1 fixes a [miscompilation in vtable generation](https://github.com/rust-lang/rust/issues/161441).

Back in Rust 1.98.0, in some cases, rustc would get it wrong and generate a trait object vtable with a null pointer
where a function pointer should be. That ends up as undefined behaviour in the
emitted code. Sometimes this might 'just' cause segfaults when the null
pointer gets loaded, but it can be grounds for
arbitrary effects too (as is par for the course with UB).

If you're keen to give us a hand by testing future releases, you could have a go at
using the beta (`rustup default beta`) and nightly (`rustup default nightly`) channels locally and in your CI. And please
[report](https://github.com/rust-lang/rust/issues/new/choose) any bugs you
happen to run into!
