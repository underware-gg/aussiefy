The Rust team has put out a new point release of Rust, 1.98.1. Rust is a programming language that's giving every man and his dog the power to build reliable and efficient software.

If you've already got an earlier version of Rust installed through rustup, getting Rust 1.98.1 is as easy as:

```
rustup update stable
```

If you haven't got it yet, you can [get `rustup`][rustup] from the right page on our website.

[rustup]: https://www.rust-lang.org/install.html

## What's in 1.98.1

Rust 1.98.1 fixes a [miscompilation in vtable generation](https://github.com/rust-lang/rust/issues/161441).

In Rust 1.98.0, in some cases, rustc would wrongly generate a trait object vtable with a null pointer
where a function pointer should be. That leads to undefined behaviour in the
emitted code. Sometimes this may 'just' cause segfaults from the null
pointer being loaded, but it's possible for it to be grounds for
arbitrary effects (as is usual for UB).

If you'd like to give us a hand by testing future releases, you might think about
using the beta (`rustup default beta`) and nightly (`rustup default nightly`) channels locally and in your CI. Please
[report](https://github.com/rust-lang/rust/issues/new/choose) any bugs you
might run into!
