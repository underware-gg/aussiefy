### Project Directory Setup

You’ll kick off by making a directory to keep your Rust code in. Rust couldn’t
care less where your code lives, but for the exercises and projects in this book,
we reckon you should make a _projects_ directory in your home directory and keep all
your projects in there.

Open a terminal and enter the following commands to make a _projects_ directory
and a directory for the “Hello, world!” project inside the _projects_ directory.

For Linux, macOS, and PowerShell on Windows, enter this:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

For Windows CMD, enter this:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Next, make a new source file and call it _main.rs_. Rust files always end in
the _.rs_ extension. If you’re using more than one word in your filename, the
convention is to split them up with an underscore. So, use
_hello_world.rs_, not _helloworld.rs_.

Now open up the _main.rs_ file you just made and punch in the code in Listing 1-1.

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save the file and head back to your terminal window in the
_~/projects/hello_world_ directory. On Linux or macOS, enter the following
commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, enter the command `.\main` instead of `./main`:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Whatever operating system you’re on, the string `Hello, world!` should print to
the terminal. If you don’t see this output, have a squiz back at the
[“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation
section for ways to get help.

If `Hello, world!` did print, good on ya! You’ve officially written a Rust
program. That makes you a Rust programmer—welcome aboard!
