The Rust team's pushed out a fresh point release of Rust, 1.98.1. Rust is a programming language that's giving everyone a leg-up to build software that's reliable and runs like a bloody dream.

If you've already got an older version of Rust in through rustup, grabbing Rust 1.98.1 is as easy as:

```
rustup update stable
```

If you haven't got it yet, you can [get `rustup`][rustup] off the right page on our website.

[rustup]: https://www.rust-lang.org/install.html

## What's in 1.98.1

Rust 1.98.1 sorts out a [miscompilation in vtable generation](https://github.com/rust-lang/rust/issues/161441).

In Rust 1.98.0, in some situations, rustc would go and stuff up a trait object vtable, putting a null pointer
where a function pointer was meant to be. That leads to undefined behaviour in the
code it spits out. Sometimes this might 'just' give you segfaults when the null
pointer gets loaded, but it's also fair game for
any old weird effects at all (as you'd expect with UB, the mongrel).

If you'd like to lend us a hand by testing future releases, you could think about
running the beta (`rustup default beta`) and nightly (`rustup default nightly`) channels locally and in your CI. Please
[report](https://github.com/rust-lang/rust/issues/new/choose) any bugs you
might trip over!
