The Rust team has put out a new point release of Rust, 1.98.1. Rust is a programming language that's giving every man and his dog the means to build reliable, efficient software.

If you've already got an earlier version of Rust installed via rustup, getting Rust 1.98.1 is as easy as:

```
rustup update stable
```

If you haven't got it yet, you can [get `rustup`][rustup] from the right page on our website.

[rustup]: https://www.rust-lang.org/install.html

## What's in 1.98.1

Rust 1.98.1 fixes a [miscompilation in vtable generation](https://github.com/rust-lang/rust/issues/161441).

In Rust 1.98.0, under some conditions, rustc would wrongly generate a trait object vtable with a null pointer
where a function pointer ought to be. That leads to undefined behaviour in the
emitted code. Sometimes it might 'just' cause segfaults when the null
pointer gets loaded, but it can also be the excuse for
arbitrary effects (as is par for the course with UB).

If you're keen to give us a hand by testing future releases, you might think about
using the beta (`rustup default beta`) and nightly (`rustup default nightly`) channels locally and in your CI. Please
[report](https://github.com/rust-lang/rust/issues/new/choose) any bugs you
happen to run into!
