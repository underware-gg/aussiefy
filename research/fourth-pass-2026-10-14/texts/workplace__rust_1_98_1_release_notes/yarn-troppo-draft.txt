G'day, Rustaceans. The Rust team's gone and put out a new point release of Rust, 1.98.1. For anyone who's been living under a rock, Rust is a programming language that's giving every man and his dog what they need to build reliable, efficient software.

If you've already got an earlier version of Rust installed via rustup, getting Rust 1.98.1 is easy as. Just run:

```

```

Haven't got it yet? No wukkas, you can [get `rustup`][rustup] from the right page on our website.

[rustup]: https://www.rust-lang.org/install.html

## What's in 1.98.1

Righto, the guts of it. Rust 1.98.1 fixes a [miscompilation in vtable generation](https://github.com/rust-lang/rust/issues/161441).

Back in Rust 1.98.0, under some conditions, rustc would get it wrong and generate a trait object vtable with a null pointer
sitting right where a function pointer ought to be. Not ideal. That leads to undefined behaviour in the
emitted code. Sometimes it might 'just' cause segfaults when the null
pointer gets loaded, and you'd be lucky if that's all, cos it can also be the excuse for
arbitrary effects (as is par for the course with UB).
