### Project Directory Setup

Strewth, where do I start? With a directory, that's where: somewhere to keep yer Rust code. Now, Rust itself doesn't give a toss where yer code lives, it's not fussy, but for the exercises and projects in this book we reckon ya make a _projects_ directory in yer home directory and keep the whole box and dice in there, nice and tidy.

So fire up a terminal and punch in these commands. They'll make ya a _projects_ directory, and a directory for the “Hello, world!” project sittin' inside the _projects_ directory.

Linux, macOS, and PowerShell on Windows mob, this one's yours:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

And for the Windows CMD crowd, it's this lot:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Righto, next ya make a new source file and call it _main.rs_. Rust files always end in the _.rs_ extension, no exceptions. And if yer filename's got more than one word in it, the convention is an underscore between 'em, so it's _hello_world.rs_, not _helloworld.rs_, which just looks like someone sat on the keyboard.

Now crack open that _main.rs_ file ya just made and type in the code in Listing 1-1. Three lines. That's the lot.

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save the file and duck back to yer terminal window in the _~/projects/hello_world_ directory. On Linux or macOS, punch in these commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, mind, it's the command `.\main` instead of `./main`, cos Windows always has to be different:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Whatever operatin' system yer on, the string `Hello, world!` oughta pop up in the terminal. If ya don't see that output, don't spit the dummy: have a squiz back at the [“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation section for ways to get some help.

And if `Hello, world!` did print? Good on ya, ya legend! Ya've officially written a Rust program. That makes ya a Rust programmer. Welcome to the club, mate, first round's on you.
