### Project Directory Setup

First up, you'll wanna make a directory to keep yer Rust code in. Rust couldn't care less where yer code lives, but for the exercises and projects in this book, we reckon ya make a _projects_ directory in yer home directory and keep all yer projects in there.

Fire up a terminal and punch in these commands to make a _projects_ directory, and a directory for the “Hello, world!” project inside the _projects_ directory.

For Linux, macOS, and PowerShell on Windows, bung this in:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

For Windows CMD, it's this:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### Rust Program Basics

Next up, make a new source file and call it _main.rs_. Rust files always end in the _.rs_ extension. If yer usin' more than one word in yer filename, the convention is to stick an underscore between 'em. So go with _hello_world.rs_, not _helloworld.rs_.

Now open up the _main.rs_ file ya just made and type in the code in Listing 1-1.

<Listing number="1-1" file-name="main.rs" caption="A program that prints `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

Save the file and duck back to yer terminal window in the _~/projects/hello_world_ directory. On Linux or macOS, punch in these commands to compile and run the file:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

On Windows, it's the command `.\main` instead of `./main`:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

Whatever operatin' system yer on, the string `Hello, world!` oughta print to the terminal. If ya don't see that output, have a squiz back at the [“Troubleshooting”][troubleshooting]<!-- ignore --> part of the Installation section for ways to get a hand.

If `Hello, world!` did print, good on ya! Ya've officially written a Rust program. That makes ya a Rust programmer, so welcome aboard, mate!
