## Decision

Activate changes and rich cards together at v3 with the accepted response fields. Keep the historical
draft bytes; package the frozen schemas and generate current fixtures through actual public operations.
Entries and riffs share one projection; constructions/imagery reuse its metadata and maker rules.
Canonical part spans address card text; occurrence spans address their own rendering. Track actual
article/case/phonetic/escaping edits rather than search for matching substrings.

Use a transient Entry view to run bounded reviewed constructions through existing selection fit and
rendering. It never enters the dictionary or entry-card map. Try it only when curated candidates fail
eligibility, before any probability roll. Literal ingredients cannot inject template fields. Unsupported
frames and result-complement conflicts remain plain. Every constructed opener obeys invention.

Public permissions and tuning remain request-local. Theme keys merge exactly over document overrides;
the same resolved policy reaches every surface. The MCP boundary hides raw preferences and invokes a
host callback once with actual numeric dials, independent of whether popularity is offered. Yarn
explicitly requests misreadable permission and receives provider-neutral reviewed material.

Add a separate version-1 pins input. It qualifies precise source anchors with the full source hash,
dictionary identity and seed. A construction keeps a complete typed recipe and persistent ID, an entry
keeps its dictionary form, and a riff keeps canonical text. Complete replay suppresses unlisted choices;
all supplied choices must be consumed. Explicit selection bypasses random choice, variety and soft
repeat weighting, never hard meaning/grammar/source/genre/theme/cap/invention checks. Replay uses the
same realiser. Markdown prepares once and offsets each unit into the full source. Results capture pins;
the changes builder can supply an optional editor sidecar outside its frozen response fields.

## Consequences and verification

The response has one coordinated schema boundary; replay can evolve independently. The service owns
accounts, stored preferences, pins in share links and deployment. The package performs no persistence
or network access. Real-emitter graph checks cover makers, keys, joins, exact warning parity and local
Unicode spans. Replay tests cover tuning removal, full recipes outside sampled pools, stacks/riffs,
imagery/garnish, Markdown, refusals and request isolation. Existing whole re-render oracles still check
alternative renderings. Source hunt/score calibration and the later kept/personal/held/selection contract
remain separate work; this decision does not approve a release, website pin or deployment.
