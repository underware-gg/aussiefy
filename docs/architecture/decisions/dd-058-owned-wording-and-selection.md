# DD-058: owned wording, selection suggestions and curated near meanings

Status: implemented; v4 frozen after the site review on 15 November 2026.

Source ownership belongs in the shared engine pass. Dictionary-owned Australian forms, understood
wordless meanings and eligible request-local personal phrases claim spans before replacement and
garnish. Kept/held words remain literal, including above-cap source swears. A shorter owned form must
not overturn a settled larger source reading. Recognition reuses the source grammar and phrase fences;
ambiguous everyday senses require independent support. No synthetic concept or dictionary entry is
created for personal wording, ambiguous forms or concept-free garnish.

One candidate/render/application path carries ordinary and near replacements and personal phrases.
English alternatives use authored sentence forms plus capture and degree checks. Literal spans move
through actual edits and are opaque to optional rewrite models, whose acceptance rule requires every
owned run intact. The engine never imports LLM or toolkit adapters.

Selection suggestions sit above translation. One observer captures actual spot state and edit traces;
output offsets map back through those traces and Markdown escaping. Candidate fallback uses the same
frame, permissions and renderer, preserves fences and names, and does not infer meaning from fuzzy
similarity. Multi-meaning selections return groups rather than one invented reading.

Curated near relations are directed data, usable only at genuinely wordless source spots and under
reviewed document/embellishment gates. Exact words, even unavailable under the current dials, block
automatic near use. Near target candidates share ordinary permissions, tuning and variety once per
source pool; selected output and every applicable alternative cite the specific relation.

The frozen v4 contract uses explicit option keys for dictionary, construction, source, English and personal
choices, with per-option replacement regions and rendering-local child coordinates. Existing dictionary,
construction and riff replay inputs remain. A null substitution target replays plain:source exactly;
other kept English choices need a separately coordinated replay input. Personal choices are never
shared as dictionary pins.
A host's personal list is resolved once per call by its adapter. The engine owns no account state.


Each selection group reports its own outcome and vulgarity-locked options. Broader-dial eligibility
uses the same candidate checks to distinguish outside_dials from a missing word or grammatical
failure. Near citations carry the target's authored plain name. Kept source options suppress identical
dictionary replacements. Headword keys omit a terminal full stop without changing stored spellings.
The adapter can set or remove its hook's personal-list cap; direct request limits remain bounded.


An explicitly pinned, eligible prefix remains replayable when a literal source choice restores a
capitalised first word. Automatic casing-confidence heuristics do not discard that explicit pin;
ordinary context/dial/budget/spacing checks and exact literal restoration remain in force. This does
not broaden automatic prefix placement or weaken unused-pin validation.
