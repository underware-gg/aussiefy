# DD-039: Certified modifier composition and replacement ownership

Status: Accepted; integrated verification passed.
Date: 20 October 2026.
Extends: [DD-034](dd-034-reviewed-semantic-degree.md), [DD-037](dd-037-contextual-matching-and-discovery.md).

## Context

Preserving every source modifier verbatim prevents valid certified expressions (`slightly hungry` →
`peckish`). Discarding a modifier without reviewing its realised meaning loses stated severity. Relational
constructions also need a threshold: an unmarked predicate cannot freely become mild inside `enough to`.

## Decision

Use a pure shared degree plan for each candidate form. Retain a qualifier when the target can carry it;
otherwise an adjective predicate with an equivalent reviewed grade may express the modifier itself.
Every shared graded meaning must agree. Unsupported and conflicting compositions remain ineligible.
Strong-adjective modifiers have an explicit bounded composition rule, independent of style intensity.

The source modifier span belongs to the replacement in both cases. Retention restores its original bytes
after predicate casing; absorption removes it exactly once. The existing replacement-span and rendering
seams serve automatic changes and editor alternatives together. Absorption does not newly enable wider
clause forms, which would require ownership of intervening frequency/aspect and other source material.

Threshold-bearing or opaque dependent constructions require matching certified lexical grade even when
it is unmarked. The same grade comparison limits inferred lookup; direct vocabulary explanations remain
broader. Bounded source-aware verification recognises local relational grade changes without claiming
exact threshold equivalence or arbitrary multi-edit alignment.

## Consequences

Certified appetite/alcohol substitutions gain fluent coverage while preserving explicit strength.
Missing certificates still limit coverage. New graded families require independent calibration; a broad
intensity number or one convenient meaning path cannot supply missing evidence. No new user parameter,
phrase-specific engine exception, model gate or default gap-filling permission is introduced.
