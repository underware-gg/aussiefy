  describe guided retellings versus supplied drafts, separate anchor-file access from draft visibility,

  README: the pinned plan uses only the supplied current-engine comparator. Frozen driver/evidence bytes

## What's done well

- The canonical translation route resolves effective document/profile/embellishment/markup/source-English
  settings. Agent/API judges share one key-free request; reference writing gets the same settings without
  toolkit vocabulary. Cache identity changes with settings and instructions.
- Legacy packets preserve protocol 1 and do not acquire current inferred defaults. New verdicts retain
  protocol 2; mixed-protocol tallying is rejected. Saved full snapshots validate completeness/types while
  accepting deliberately unconventional advanced combinations.
- The existing study driver accepts a selected plan and records its path/hash. It replays actual calls,
  binds origin and report evidence, and uses production judging rather than another contract definition.
- The Bible has exact passage/edition/extraction/public-domain evidence. Synthetic sources have individual
  own-work declarations. Source-bearing derivatives inherit per-source provenance; aggregate-only files
  have separate project declarations.
- Independent checks found all 87 frozen engine hashes and driver/source/anchor hashes correct. Both
  judges received byte-identical packets; originals, briefs, settings, outputs and dispatch logs match
  between repeats. The 15 additional brief constructions remain in hash-bound origin metadata.
- Twelve blind assessments over six sources contain 192 literal criterion-evidence fields. Both judges
  preferred the guided retelling on all six cases. The report retains severity disagreements and weak
  instruction voice, distinguishes assessments from source count, and makes no causal cross-study claim.
