## What's done well

Mapping effects are conditional source knowledge rather than global labels on ordinary indefinite slang.
Document types feed resolved settings; exact overrides win, and degree/severity remains independent.
Precise same-span meanings are not contaminated by another reading's effect. Plans, explanations, lookup
and alternatives use the same eligibility seam. Original-aware verification excuses only paired occurrences,
retaining unrelated missing numbers and documenting ambiguous alignment limits.

Source repairs use concept splits, matching context and shared object validation. No slang ID enters Python.
All entries, statuses, flags and registers are retained. Independent source comparison confirms exactly
627 new reviewed entry/URL pairs: 774 pairs across 688 IDs become 1,401 pairs across 1,227 IDs. The merge has
no unreviewed extras, omissions, duplicate pairs or unknown IDs. Sources support bounded senses rather
than every trigger, exclusive origin or population-frequency claims.
