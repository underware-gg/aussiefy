# Design reviews

Repository design reviews, kept as written. Each lists its findings with evidence, the fixes chosen and
what was done; line numbers and file names in them refer to the code as it was at the time, and some name
commands that have since been renamed. Decisions they led to are recorded in [decisions](../decisions/README.md).
